NullRoute

Blocking happens inside Chrome's own request engine. Nothing you browse is sent anywhere.

Filter lists

Each list is compiled into Chrome rules when the extension is built. Turning one off takes effect immediately.

Defaults for every site

Each site uses these unless you change it from the toolbar popup. Site changes win over defaults.

Trackers & adsAggressive also blocks every third-party script and frame. Expect some sites to break.
Block scriptsStops all JavaScript. Most modern sites won't work.
Block cross-site cookiesEmbedded third parties can't read or set cookies. Can break sign-in widgets.
Block fingerprintingAdds per-page noise to canvas and audio readings and hides your exact CPU count.
Forget sites when closedClears a site's cookies and storage when its last tab closes. You'll be signed out.

Sites with their own settings

    Dangerous sites

    Warns before opening sites on phishing, scam and malware feeds. Each address is checked against a list stored in Chrome; only a rare possible match downloads a small, anonymous batch of hashes to confirm, so the sites you visit are never sent anywhere.

    Cross-site trackers

    Catches trackers no list knows yet: a third party that receives the same identifier from two different sites is following you between them. Only scrambled fingerprints of those identifiers are kept, and they're forgotten when Chrome closes.

    Detect cross-site trackersWatches requests the lists let through. Never blocks anything by itself.
    Block the trackers it findsBlocks them wherever they're embedded. Allowed sites are never affected.
